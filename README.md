# 5027251011-Week-9-Pemrograman-Web

Aplikasi web untuk menyimpan lagu berdasarkan **suasana hati dan momen** saat mendengarnya, bukan berdasarkan genre. Setiap lagu tampil sebagai kartu bergaya kaset dengan warna sesuai mood-nya, misalnya lagu untuk "hujan sore sambil ngopi", "begadang ngerjain tugas", atau "baper tengah malam".

**Nama:** Revalinda Bunga Nayla Laksono
**NRP:** 5027251011
**Mata kuliah:** Pemrograman Web

## Fitur

- **Lihat semua lagu (GET)**: daftar lagu tampil sebagai kartu kaset berwarna sesuai mood.
- **Tambah lagu (POST)**: form berisi judul, artis, mood, cerita singkat, dan link lagu.
- **Ubah lagu (PUT)**: tombol Edit mengisi form dengan data lama, lalu disimpan sebagai perubahan.
- **Hapus lagu (DELETE)**: tombol Hapus dengan dialog konfirmasi.
- **Lagu acak sesuai mood**: memilih satu lagu secara acak dari mood yang dipilih.
- **Pencarian, filter mood, dan pengurutan** di halaman daftar.
- **Statistik**: total lagu dan mood terbanyak.
